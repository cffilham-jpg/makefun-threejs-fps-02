# MERIDIAN YARD

An original three.js tactical FPS: defend a dusk industrial depot with two squadmates against three Strikers. Buy equipment, hold two sites, and defuse the charge. First to five rounds wins.

Run `node serve.ts`, then open http://localhost:8080. No installation or network assets needed.

- WASD: move; mouse: look; left click: fire
- R: reload; Ctrl/C: crouch; Space: jump
- B: buy during the 15-second buy phase; 1–6: purchase while menu is open
- 1: primary; 2: pistol; 3: grenade, then click to throw
- Right mouse: scope with Longbow; hold E: defuse (5 seconds)
- Escape: pause/release pointer; click Resume to return
